WEBSYS TA5 - SWIFTPOS (LARAVEL 12 APPLICATION SOURCE)

IMPORTANT: THIS ZIP DOES NOT INCLUDE vendor/.
It is complete application source, but it cannot run offline immediately after
extraction. Composer must download Laravel and its dependencies once. Downloads
were blocked in the authoring environment, so the dependencies could not be
bundled. This ZIP does not resolve the Packagist connection problem by itself.

EXTRACT

2. The following should be directly inside that folder:

   public, resources, routes, storage.
3. If WebSysTA5 already contains work you want to keep, back it up first.
   Avoid creating WebSysTA5\WebSysTA5 by nesting the extracted folder.

FIRST SETUP - A WORKING INTERNET CONNECTION IS REQUIRED
1. PHP 8.2.12 and Composer from your screenshot are suitable.
2. Double-click Setup.bat. It installs the dependencies, creates the local
   application key if missing, and checks route registration and Blade compilation.
3. If it reports curl error 28, switch to another network/provider and run it again.
4. Once setup finishes, double-click Start-POS.bat.
5. Open http://127.0.0.1:8000 in a browser. Keep the server window open.

AFTER FIRST SETUP
Start-POS.bat starts the server again without downloading dependencies.
No npm build, MySQL server, or database migration is needed for these four pages.

IF YOU NEED AN OFFLINE COPY FOR YOUR COMPUTER
A trusted computer with working internet and PHP/Composer can run Setup.bat
(or composer install and php artisan key:generate) on this project first.
Then copy the ENTIRE folder, including vendor/ and composer.lock, to your PC.
Do not run composer create-project inside this already-populated project.

All four links appear in the shared navigation. Click each link from each page.

DEPENDENCY NOTES
composer.json targets Laravel 12 and resolves dependencies for PHP 8.2.12.
The first successful installation creates composer.lock and vendor/.
Keep composer.lock with the project so future installs use the resolved versions.
.env is preconfigured for local use with file sessions/cache and a sync queue.
The application key is blank in this source ZIP; Setup.bat generates it locally.
Database configuration is included for future learning, but no database records
or tables are required by the four pages.
